🎬 纯浏览器录屏工具

无需安装 · 全程在本地浏览器完成 · 仅支持桌面端 Chrome / Edge / Firefox / Safari
就绪 00:00:00 —
● 实时预览（录制中）
使用说明：
• 点击「开始录制」后，浏览器会弹出系统级选屏框，选择「整个屏幕 / 应用窗口 / 浏览器标签页」并确认。
• 开启摄像头时，浏览器会再请求一次摄像头权限（画中画合成在本地完成，不上传）。
• 录制中可在浏览器地址栏附近的浮条点「停止共享」结束；本工具也会自动收尾。
• 优先输出 MP4（Chrome/Edge/Safari 支持）；不支持的浏览器（如 Firefox）自动回退 WebM。
• 如选屏框中取消了授权，录制不会开始（属正常行为）。
• 系统声音说明：选屏框里要勾选「共享音频 / Share audio」才会录到声音；录单个应用窗口时多数浏览器不提供音频；macOS 的浏览器不支持网页捕获系统音频，只能用「混入麦克风」录人声。
